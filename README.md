# 海绵宝宝 · 主题静态网站

一个以《海绵宝宝》动画为主题的多页面静态网站，使用原生 HTML5 + CSS3 手写完成，无框架、无构建工具、无第三方 JS 库，下载后双击即可浏览。

项目包含首页、角色介绍、图集欣赏、在线视频、经典台词、获奖记录、联系我们以及登录 / 注册共 **9 个页面**，并配套独立的样式表与图片、音乐、视频素材。

---

## 页面一览

| 文件 | 页面 | 主要内容 |
| --- | --- | --- |
| `index.html` | 首页 | 剧情简介、动画制作人员卡片、片头视频、建筑场景图组 |
| `role_intro.html` | 角色介绍 | 海绵宝宝、派大星、珊迪、蟹老板、章鱼哥、痞老板、小蜗等角色档案 |
| `atlas.html` | 图集欣赏 | 剧照 / 场景图片墙展示 |
| `video.html` | 在线视频 | 站点内置视频播放 + 腾讯视频、优酷、B 站、芒果 TV 外链 |
| `classicline.html` | 经典台词 | 动画经典台词展示 |
| `awards.html` | 获奖记录 | 动画所获荣誉与奖项列表 |
| `contactus.html` | 联系我们 | 姓名 / 电话 / 邮箱 / 留言表单 |
| `login.html` | 登录 | 账号 + 密码登录表单 |
| `rigister.html` | 注册 | 邮箱 / 账号 / 双密码注册表单（含重置按钮） |

顶部导航与页脚版权信息在所有页面中统一复用，通过 `css/common.css` 统一控制头部、导航栏与版式，`css/style.css` 负责各页面模块样式。

---

## 技术栈

| 分类 | 说明 |
| --- | --- |
| 结构 | 原生 HTML5，单页独立文件，相对路径引用资源 |
| 样式 | 原生 CSS3（Flex / 浮动布局、卡片、渐变背景），双文件拆分：`common.css` 公共框架 + `style.css` 页面样式 |
| 媒体 | `<video>` / `<audio>` 原生标签直接播放本地 mp4 / mp3 |
| 交互 | 原生 JavaScript（`js/main.js`）：统一拦截表单提交并弹出轻提示 |
| 依赖 | 无任何外部框架、无 CDN 引用，可完全离线运行 |

## 本地运行

**方式一：直接打开**

双击 `index.html`，浏览器即可渲染整站。视频、音乐、图片均为相对路径，无需任何服务端环境。

**方式二：本地静态服务器（推荐，避免个别浏览器对 `file://` 的媒体限制）**

```bash
cd 海绵宝宝
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

**方式三：VS Code** 装 Live Server 插件，右键 `index.html` → Open with Live Server。

## 已知问题与待优化

- `login.html`、`rigister.html`、`contactus.html` 三个表单没有后端接口，由 `js/main.js` 统一拦截提交并弹出「演示页面，无后端」轻提示，不会真正发送请求；如需真实登录 / 留言功能，需要另外接入服务端。
- `rigister.html` 文件名拼写有误（应为 `register.html`），如需改正需同步修改 `index.html` 中的导航链接。
- `video.html` 中部分视频为第三方平台外链，离线或网络受限时无法播放。
- 图片与视频素材共约 137MB 且未压缩，仓库体积偏大；后续可将图片转为 WebP、视频转码降码率，或改用 Git LFS 管理大文件。
- 页面为纯静态实现，无响应式适配，窄屏下版式会挤压变形，可补充媒体查询做移动端适配。
